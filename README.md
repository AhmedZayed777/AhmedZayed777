# 🚀 Featured AI Projects

## 🏥 Chest X-Ray Pneumonia Detection

A deep learning system for detecting **pneumonia from chest X-ray images** using CNNs and Transfer Learning.

The project compares a custom CNN with **ResNet50**, which was pretrained on ImageNet and adapted for pneumonia classification.

### 🧠 Models

**Custom CNN**

* Multiple Conv2D layers
* MaxPooling
* Built from scratch

**ResNet50**

* ImageNet pretrained backbone
* Transfer Learning
* Fine-tuned for binary classification

### 📊 Results

| Model      | Test Accuracy | Precision | Recall | F1-Score |
| ---------- | ------------: | --------: | -----: | -------: |
| Custom CNN |           86% |      0.84 |   0.97 |     0.90 |
| ResNet50   |     **89.4%** |  **0.90** |   0.93 | **0.92** |

### ⚙️ Techniques

* Data augmentation
* Class weighting for class imbalance
* Validation split
* Early stopping
* Learning-rate scheduling
* Model evaluation using precision, recall, and F1-score

### 🛠️ Tech Stack

**Python • TensorFlow • Keras • ResNet50 • OpenCV • Scikit-learn • Matplotlib**

## 🛰️ Water Body Semantic Segmentation

A Computer Vision project focused on **semantic segmentation of water bodies from multispectral satellite imagery**.

The project explores both a standard **U-Net** architecture and a lightweight **MobileNetV2-based U-Net**.

### 🌍 Input Data

The model uses multispectral satellite imagery containing:

* 🔵 Blue
* 🟢 Green
* 🔴 Red
* 🟣 NIR
* 🟤 SWIR
* 💧 NDWI — Normalized Difference Water Index

### 🧠 Models

**U-Net**

A standard encoder-decoder architecture for semantic segmentation.

**MobileNetV2-U-Net**

A lightweight U-Net architecture using **MobileNetV2 as the encoder backbone**, designed to reduce computational requirements while maintaining segmentation performance.

### ⚙️ Techniques

* Multispectral image processing
* NDWI feature integration
* Per-channel normalization
* Semantic segmentation
* Encoder-decoder architectures
* Model comparison

### 📏 Evaluation

**Intersection over Union (IoU)**

**Python • TensorFlow • Keras • NumPy • OpenCV • Satellite Imagery**
